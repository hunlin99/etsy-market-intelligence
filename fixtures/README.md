# Synthetic golden fixtures

All ten JSON files are authored test scenarios, not real Etsy research or verified policies. The source type and observation text explicitly mark them as synthetic. Do not use their market statements as commercial evidence.

Expected verdicts are in `tests/golden-manifest.json`. Scenarios cover no data, review proxies, conflicting sources, user bias, a hypothetical policy failure, stale fees, bounded Proceed, nonviable economics, failed sources, and seasonality.

Private seller data and identifiable customer information must not be added to these public examples.
