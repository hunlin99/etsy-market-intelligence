# Etsy Market Intelligence

An evidence-driven skill for evaluating digital product opportunities.

## Status

Initial repository scaffold only. Research logic, schemas, fixtures, validation, and runtime installation are not implemented or verified. This repository does not perform live Etsy research.

## Structure

- `SKILL.md`: draft skill entry point; runtime compatibility remains unverified.
- `core/`: intake, evidence standards, workflow, critical review, and decision rules.
- `schemas/`: planned Research Record JSON Schema.
- `templates/`: planned Quick Check and comparison outputs.
- `fixtures/`: planned fixed research scenarios.
- `tests/`: golden cases and acceptance checklist.
- `scripts/`: optional validation utilities.
- `docs/`: original development specification and scope notes.

## Next steps

Confirm the target skill runtime, define Research Record v0.1, implement Phase 1 rules and templates, then add and verify 8–10 golden scenarios. Phase 2 and Phase 3 are future scope.

The uploaded specification is reference material, not evidence that any feature has been implemented or tested.
